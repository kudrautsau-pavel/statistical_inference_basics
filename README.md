1. Formulation of hypotheses
	•	H₀ (null hypothesis) = status quo: «no effect».
	•	H₁ (alternative hypothesis) = what we want to test: «there is an effect».

Example:
	•	H₀: the mean height of students = 180 cm
	•	H₁: the mean height of students ≠ 180 cm

⸻

2. Experiment and calculation of the statistic
	•	Collect data (sample).
	•	Compute the test statistic (e.g., t- or z-value).
	•	Compute the p-value = the probability of observing such or more extreme data if H₀ is true.

⸻

3. Comparison with α
	•	If p-value ≤ α → the result is considered statistically significant → we reject H₀ in favor of H₁.
	•	If p-value > α → the data are insufficient to reject H₀.
